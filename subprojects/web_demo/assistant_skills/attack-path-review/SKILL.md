---
name: 攻击路径审查
description: 结合实际输入、可信路线与知识库解释攻击路径。
---

1. 用 search_results 查指定风险ID或资产的完整路径，再用 search_inputs 核对相关端点和协议。
2. 部件资产终点为受攻击ECU，数据资产终点为存储数据的ECU，信号资产终点为接收信号的ECU；入口以项目提供的外部接口为依据。
3. 路径按外部接口到入口ECU、ECU之间的协议跳分段；检查每段攻击动作和最后的直接损害结果。
4. 必要时 retrieve_knowledge 查询相关技术及案例，区分知识库案例与本项目已证实的路线。
5. 不把攻击向量分类当作路径正文，不凭缺失资料推定漏洞已经存在。
6. 用户要求修订正文时调用 revise_report.operations；需要模型重新分析时调用 rerun_assets，原报告保留。
