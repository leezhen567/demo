---
name: 安全需求与法规核对
description: 按匹配逻辑核对需求编码、国标法规与附录5映射。
---

1. 用 search_results 查当前资产、属性和路径，以及已有安全需求。
2. 用 retrieve_knowledge 检索安全需求匹配逻辑2.0及相关知识，使用 search_security_requirements 查权威工作簿记录。
3. 需求原文、国标法规编码和附录5 Part B/C映射必须来自同一条需求记录；不编造编码。
4. 区分规则候选、模型选择、已经实施的控制；“已匹配”不等于“已实施”。
5. 关键零部件、操作系统等缺失信息保持未知，不把未评估条件说成通过。
6. 解释匹配依据和缺口，给出可追溯的需求编码及来源。
